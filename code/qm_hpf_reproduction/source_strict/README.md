# QM-HPF source-strict runner

该目录只接受 Zhang 等（2025）源论文中可以由正文、原始数据或作者确认得到的参数。现有 `../qm_hpf.py` 是 `QM-HPF-like` 审计实现，不能被本目录直接当作严格复现。

运行入口为 `run_source_strict.py`。默认读取同目录的 `source_config.json`；该文件不存在或含有 `UNRESOLVED`/`REQUEST_AUTHOR` 时，程序会生成 `failure_artifacts/strict_blocked.json` 并退出。这样可以防止把量子编码边界、初始粒子分布等自行补设值写入严格复现。

`source_kernel.py` 已实现一维模型的预测、权重更新、高低权重划分、旋转/交叉候选、接受率、可选最终系统重采样和逐步 trace。它只接受已经闭合的配置和源旋转符号表；缺少任一源证据时由入口门阻断。

当前可直接锁定的源事实：

- 一维模型时间长度为 200，粒子数为 100，$x_0=1$；
- 观测噪声方差为 1；
- 过程噪声方差实验包括 1、2、3；
- Eq. (6)、(14)--(18) 和接受率 Eq. (16) 的总体结构。

严格运行前仍需从源代码、作者补充材料或作者确认获得：编码范围、编码位数、连续解码规则、振幅持久化规则、低权重遍历和随机数顺序、接受后权重重算、最终重采样，以及电池 SOC 分支的完整 RC 参数和数据。

输出目录每个 seed 至少包含：逐步粒子、权重、量子比特概率、候选粒子、接受标志、RNG 状态、原始指标、配置和 manifest。当前没有填充这些缺失项，因此严格运行会 fail closed。

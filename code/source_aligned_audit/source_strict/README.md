# EC-QPF source-strict runner

上一级 `ecqpf_operator.py` 是已经完成的选择模块审计。本目录面向 Wan et al.（2021）的完整 180 步 IMU 跟踪复现，默认使用源 Eq. (22) 的字面形式，并且不会把平方距离或尺度解释偷偷替换进去。

严格运行需要一个完整的 `source_config.json`。缺少表 II 参数、IMU 轨迹生成规则、初始粒子分布、$\beta$ 到椭圆尺度的关系、空子集处理、平局规则、复制分配、随机种子或 CMCR-PF/SR-PF 基线时，程序会生成 `failure_artifacts/strict_blocked.json` 并停止。

完成后，每个 seed 和每个时间步应保存：IMU 输入、预测粒子、协方差和椭圆索引、量子概率群体、二进制测量、适应度、全局/个人最优、停止原因、复制结果、估计值和 RNG 状态。Eq. (22) 的量纲问题必须同时记录为源公式审计字段。

`source_kernel.py` 已实现椭圆筛选、源 Eq. (22) 字面适应度、二进制观测、持久概率更新、停止条件、平局规则和复制分配接口。完整 180 步 IMU 预测仍由严格配置提供，不能由当前模块审计中的合成中心替代。

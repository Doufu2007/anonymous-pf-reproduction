# 类别四补强实验可行性评估（独立记录）

日期：2026-10-08

## 结论

目前最快可以安全落地的是第二种量子启发式方法的**独立重实现**，而不是“真实公开数据集”。我已在本目录实现了一个 QGPF-like 实验，基于魏颖、郭鲁（2021）《基于量子遗传粒子滤波的无线传感器网络的目标跟踪算法的研究》的公开模型描述。该实现没有作者代码，且原文没有给出完整的状态边界、观测噪声方差、遗传接受准则等细节，因此结果只能标记为 `INDEPENDENT_REIMPLEMENTATION`，不能写成严格复现。

真实数据集方案目前不适合直接并入主稿：NASA PCoE 锂电池数据有电压、电流、温度和容量测量，但没有可直接使用的逐时刻 SOC 真值；需要先确定电池等效电路模型、库仑积分初值、容量衰减处理、训练/评估循环划分和 SOC 误差定义。若没有这些步骤，实验会把由模型假设产生的“伪真值”误当成测量真值，审稿风险比合成基准更高。

## 已实现的第二种方法

目录：`code/qgpf_reproduction/`

文件：

- `qgpf.py`：四维恒速目标跟踪模型、Bootstrap PF、量子启发式遗传重采样 PF；
- `run_qgpf.py`：固定种子运行器，保存 manifest、truth/observation/estimate 数组、raw metrics 和 summary；
- `test_qgpf.py`：3 个边界/有限性测试；
- `README.md`：来源事实与实现假设；
- `runs-main-30/`：30 个固定种子（0--29）的可审计主运行。

实现中保留的来源事实：状态 `[x,v_x,y,v_y]`、恒速转移矩阵、距离观测 `sqrt(x^2+y^2)`、二进制量子染色体、量子旋转更新、权重作为适应度、保留高权重粒子。

明确记录的实现假设：观测噪声标准差为 1.0；原文列出的噪声对角项按加性标准差使用；四个状态坐标分别使用 10 位编码；位置边界为 `[-1000,1000]`、速度边界为 `[-100,100]`；保留 20% 精英；每个低权重粒子运行 4 代；旋转角从 `0.08π` 线性减到 `0.01π`；粒子数设为 200。所有假设均写入每个 run 的 `manifest.json`。

运行命令：

```powershell
从 `code/qgpf_reproduction/` 目录运行以下命令：
python -m unittest -v
python run_qgpf.py --seeds 0:2 --out-dir runs-pilot-3
```

这个方向的试运行没有恢复魏颖、郭鲁论文报告的优势；QGPF-like 在当前明确假设下明显差于 Bootstrap PF，且约慢 640 倍。该结果可作为“独立重实现未恢复源文献排序”的审计证据，但不适合作为主稿中支持量子优势的结果。不要把 3 个种子的试运行写成最终统计结论，也不要把实现假设称为作者算法的唯一实现。

## 对主稿的建议

1. 目前可以安全地把 QGPF 作为第二种量子启发式方法的“可运行性案例”和复现边界案例；若纳入正文，应使用 `independent reimplementation`、`reported advantage not recovered` 等措辞，并单独列出假设。
2. 若目标是类别四 SCI，先不要用当前 QGPF 试运行替代 QM-HPF 主实验。继续扩展 QGPF 前，应先做参数敏感性（状态边界、精英比例、旋转角、代数）和对照实现检查，否则运行开销高、结果方向不稳定。
3. 真实数据集应作为后续增强路线：优先选带公开参考轨迹的二维跟踪数据集（观测与真值同时提供），再迁移 QGPF/QM-HPF；NASA 电池数据只有在建立并验证 SOC 标注流程后才可使用。
4. 若时间有限，论文应保留当前 QM-HPF 30-seed 统一基准，并把 QGPF 实验放在可复现性附录或“第二方法试验”小节；不要为凑方法数量声称 QGPF 已经复现成功。

## 真实数据集路线的最小工作包

- 固定数据版本和下载 SHA-256；
- 明确参考轨迹/标签的来源，避免用滤波器输出当真值；
- 固定训练/评估时间段，禁止按测试误差调参；
- 为 Bootstrap PF、QM-HPF、QGPF 使用同一观测、粒子预算、种子和指标；
- 至少 20 个固定种子，保存每次预测、RMSE、MAE、ESS、运行时间和环境 manifest；
- 先通过单元测试和同种子双跑一致性，再写进正文。

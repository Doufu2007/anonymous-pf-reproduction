# Anonymous reproduction package

This repository contains the code and generated benchmark outputs for an anonymous manuscript on quantum-inspired particle filtering.

## Contents

- `code/qm_hpf_reproduction/`: QM-HPF-like independent audit, frozen configuration, raw metrics, and analysis.
- `code/qm_hpf_reproduction/runs/fair-budget-30/`: the 30-seed exploratory likelihood-cap supplement, including raw outputs, guardrails, and analysis evidence.
- `code/qm_hpf_reproduction/native_v4/qm_hpf.py`: the exact native-run implementation whose SHA-256 is recorded in the archived v4 manifest.
- `code/qgpf_reproduction/`: QGPF-like independent audit and raw outputs. It is an independent audit, not a strict reproduction of the source algorithm.
- `code/classical_benchmark/`: classical particle-filter reference benchmark.
- `metadata/search_ledger.csv`: literature-search and screening ledger.
- `metadata/citation_registry_2026-10-08.json`: citation metadata audit snapshot.

All benchmark trajectories are generated by the supplied scripts. No human,
clinical, proprietary, or personal data are included.

## Environment and reruns

The recorded environment is Python 3.13.7 with NumPy 2.4.2; the supplementary
budget run also used SciPy 1.17.1. Run from the relevant directory:

```powershell
cd code/qm_hpf_reproduction
python run_reproduction.py --seeds 0:29 --out-dir runs-main-30-rerun
python analyze_results.py runs-main-30-rerun

cd ../qgpf_reproduction
python run_qgpf.py --seeds 0:29 --out-dir runs-main-30-rerun

cd ../qm_hpf_reproduction
python -m unittest test_budget_benchmark -v
python run_budget_benchmark.py --plan fair_budget_plan.json --out-dir runs/fair-budget-30-rerun
python analyze_budget_benchmark.py runs/fair-budget-30-rerun
```

The archived native QM-HPF-like v4 code hash is
`312f3f5d4d9cac0d2758e5a7549ed7aa3fa6bffc832b49fb82ff622c82d89b36` and is
available in `code/qm_hpf_reproduction/native_v4/qm_hpf.py`. The fair-budget
runner uses the budget-aware implementation in the parent directory and writes
new runs to a new directory; it refuses to overwrite the archived run bundle.

The fair-budget archive retains the original source-artifact hashes in
`source_provenance.json`, but the source paper and extracted full text are not
included in this repository. No third-party article full text is redistributed.
